## Вариант: линейная интерполяция и методом кубических спалайнов
Цель: получить навыки работы с вводом/выводом, потоковой обработкой данных, командной строкой.

## Краткий отчёт

- **Функциональность**: линейная интерполяция отрезками и интерполяция натуральным кубическим сплайном в потоковом режиме. Аргументы CLI позволяют выбирать алгоритмы (`--linear`, `--cubic`, `--no-linear`, `--no-cubic`) и шаг дискретизации (`--step <double>`). Вход — упорядоченные точки `x y` (поддерживаются `;`, `,`), вывод — поток рассчитанных точек.
- **Структура**:
  - `src/Linear.hs` — потоковая линейная интерполяция.
  - `src/Cubic.hs` — построение и вычисление кубических сплайнов.
  - `src/Lab3.hs` — парсинг входа, выбор алгоритмов, слияние потоков, вывод.
  - `app/Main.hs` — точка входа CLI.
  - `test/Spec.hs` — Hspec-тесты.
- **Запуск**:
  - Пример: `cat example-stream.txt | stack run -- --linear --step 0.5`
  - Оба алгоритма по умолчанию: `cat example-stream.txt | stack run -- --step 0.25`
- **Формат входа**:
  ```
  0 0
  0.5 0.48
  1 1
  1.5 1.3
  2 0.9
  2.5 1.4
  3 2.0
  ```
  Допускаются `;`/`,` в качестве разделителя.
- **Тесты**: `stack test` (покрывают корректность значений интерполяции, порядок x, парсинг, выбор алгоритмов).
- **Стиль**: HLint и Fourmolu подключены в CI (`.github/workflows/ci.yml`), локально — `hlint src test` и `fourmolu -m check src test`.
